จัดการกิจกรรมและข่าวสาร

กำลังเปิดระบบจัดการ… เข้าสู่ระบบด้วยบัญชี GitHub ที่มีสิทธิ์แก้ไขเว็บไซต์

เลือก “กิจกรรมและข่าวสาร” → เพิ่มกิจกรรม → กรอกข้อมูลและรูป → ตรวจตัวอย่าง → เผยแพร่

หลังเผยแพร่ รอ Cloudflare อัปเดต กิจกรรมล่าสุด 6 รายการจะแสดงบนหน้าแรก และทุกรายการจะอยู่ในหน้ากิจกรรม
